# Новогодний подарок Яндекс Плюса

Лендинг-открытка: снег, гирлянды, атласный бант. По кнопке «Открыть подарок» бант растворяется и появляется 3D-карта «12 месяцев» с промокодом, а ниже — блоки про сервисы Плюса.

Сайт: https://yandex-plus-podarok.vercel.app

## Запуск у себя

Сайт статический, сборка не нужна — достаточно любого статического сервера:

```sh
git clone https://github.com/serjmax/yandex-plus-podarok.git
cd yandex-plus-podarok
npx serve .
```

Откройте http://localhost:3000. Открывать `index.html` напрямую из файла не получится: модули и шрифты загружаются только по http.

## Промокод

Промокод берётся из ссылки: `?code=ABC123` — латинские буквы, цифры и дефис, до 24 символов. Без параметра показывается пример `A1B2C3D4E5F6`. Код можно скопировать по клику. Это прототип, в будущем код будет приходить с бэкенда по персональному токену.

## Публикация

Проект готов для [Vercel](https://vercel.com): импортируйте репозиторий (Add New → Project), настраивать ничего не нужно. Заголовки кэша заданы в `vercel.json`, а `.vercelignore` не выкладывает исходники карты и Three.js.

Из консоли:

```sh
npx vercel@latest deploy --prod
```

## Устройство

| Путь | Что это |
| --- | --- |
| `index.html` | Разметка: стартовый экран с бантом, страница с картой, блоки сервисов, подвал |
| `styles.css` | Стили, адаптив (телефон — до 999 px, узкий телефон — до 600 px) |
| `script.js` | Подгонка банта под экран, открытие подарка, переливы гирлянд за курсором, блики блока, копирование промокода |
| `src/snow.js` | Снег на canvas |
| `src/card3d.min.js` | Собранная 3D-карта, её и подключает страница |
| `src/card.js`, `src/card3d.js` | Исходники карты: металл, гравировка, сцена Three.js |
| `vendor/` | Three.js для сборки карты |
| `assets/` | Картинки и SVG, `fonts/` — шрифты YS Display и YS Text |

После загрузки картинки или стили меняются через параметр `?v=` в `index.html`: при замене файла увеличьте номер, иначе браузер возьмёт старую версию из кэша.

## Сборка 3D-карты

Нужна только при правках в `src/card.js` или `src/card3d.js` (нужен Node.js):

```sh
sh tools/build-card.sh
```

Скрипт собирает `src/card3d.min.js` через esbuild. После сборки увеличьте `?v=` у `card3d.min.js` в `index.html`.

## Ветки

Основная версия — `main`. Остальные ветки — варианты дизайна:

| Ветка | Что в ней |
| --- | --- |
| `main` | Текущий сайт |
| `design/bells` | Рабочая ветка основного дизайна: изменения сначала проверяются здесь, потом переносятся в `main` |
| `design/garland-shimmer` | Перелив гирлянд за курсором |
| `design/garland-sweep` | Перелив гирлянд медленно идёт слева направо сам |
| `design/snow-video`, `design/bow-video` | Варианты стартового экрана с видео |
| `design/light`, `design/dark-block`, `design/gradient-noise` | Ранние варианты оформления |

## Права

Шрифты YS Display и YS Text, логотипы и иллюстрации принадлежат Яндексу. Three.js распространяется по лицензии MIT (`vendor/THREE-LICENSE.txt`).
